This is an interactive 1-stop-shop for all things NIST Technical Publications related. The full database has been presented on a single pain of glass, with search functionality, linking a ods workbook, to d3.js node relationships visualisation. The NIST publications are all linked together by familes, topics, and keywords which can be searched. Upon search, the list of all connected documents should appear in alphabetical order, and then when you click on any of those documents, the document abstract is shown followed by a link to the webpage location.

I am certain this concept can be used to integrate into any database, to enable easy document look up while preserving data-access through the use of url's, saml, sso, mfa, and other user-authentication permissions access control. Due to the speed of the look up this now runs faster than using the NIST CSIRT website.

I have tried to obtain help and support during this project, but I just did the whole thing by myself, leaning on whatever tools and resources were freely available.
