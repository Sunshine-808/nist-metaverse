This represents a coloured node-relationship model of the full NIST technical publications series; orienting around NIST publications, topics, families, and keywords.
The search functionality uses Javascript as an overlay to the ods database. This uses a mix of python, java, html, css, and linux software to operate. The backend data is fully flexible and can be altered with ease by any individual. The python and java scripts take care of the rest.

Due to overlap with ElasticSearch and concerns of Intelectual Property, this script is bespokely developed for my self learning, and personal accessibility in supporting me find key documents across a 1000 document database. This is not a product for sale.

Note:
Unfortunately the keywords_links.json file is 77.5Mb and cannot be uploaded to github. It can be synthensised from the ods documents via use of the python scripts.
